## 部署到 Cloudflare Pages

### 方式 A：直接拖拽（最简单，5 分钟）

1. 注册 https://dash.cloudflare.com （免费）
2. 左侧 **Workers 和 Pages** → **Create application**
3. 选 **Pages** 标签 → **Upload assets**（直接上传）
4. 把**整个 `energy-briefs/` 文件夹**（含 `assets/`）打成 zip 拖进去
5. 项目名：`energy-briefs`（决定子域名 `energy-briefs.pages.dev`）
6. 等几十秒 → 拿到 `https://energy-briefs.pages.dev` ✅

### 方式 B：接 GitHub 自动部署（推荐长期用）

1. 注册 https://github.com （免费）
2. 装 GitHub Desktop：https://desktop.github.com
3. 在 GitHub Desktop 把 `energy-briefs/` 文件夹创建为本地仓库
4. 提交 + 推送到 GitHub
5. Cloudflare Dashboard → Pages → **Connect to Git** → 选这个仓库
6. 配置：
   - Framework preset: **None**
   - Build command: **（留空）**
   - Build output directory: **`/`**
7. 之后改 HTML → GitHub Desktop Commit + Push → Cloudflare 自动部署

### 绑定自定义域名

- 域名可在 Cloudflare Registrar 买（成本价）
- 也可在 Namecheap / 阿里云 等买，然后手动加 CNAME 指向 `your-project.pages.dev`
- Cloudflare 自动签发 SSL 证书，5-10 分钟生效

## 故障排查

| 症状 | 原因 | 解决 |
|---|---|---|
| 总览页打不开 | `index.html` 缺失或大小写不对 | 确认根目录有 `index.html` |
| 点卡片 404 | 文件名大小写不对 | 全部用小写英文名 `laos.html` / `myanmar.html` 等 |
| 中文文件名 404 | Cloudflare Pages 不支持非 ASCII | 用英文文件名（已处理） |
| 图表不显示 | ECharts 没加载 | 检查浏览器控制台，确认 `assets/js/echarts.min.js` 200 OK |
| 中文乱码 | 编码不是 UTF-8 | VSCode 右下角切到 UTF-8 |
| 大陆访问慢 | Cloudflare 免费版无大陆节点 | 可考虑加阿里云 OSS 镜像（进阶） |
